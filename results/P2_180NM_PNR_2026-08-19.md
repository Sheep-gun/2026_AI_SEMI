# P2 180 nm physical implementation 결과

## 확인 결론

주최측 공식 웹 공지, OT PDF와 2026-08-13 Q&A 질문지를 다시 확인했지만 `180 nm` 공정 의무나 공통 PVT 조건은 서면으로 공개되지 않았다. Q&A 질문지에는 참가팀이 공정·PVT·Innovus·pre-layout 제출 범위를 질문한 내용만 있고 공개된 답변은 없다.

- 공식 OT 안내: <https://www.disu.ac.kr/LOCnLOS/AIX/notice?bbsidx=8796&md=v>
- 공식 Q&A 질문지 안내: <https://www.disu.ac.kr/LOCnLOS/AIX/notice?bbsidx=8824&md=v>

반면 대회 서버에 제공된 Liberty header는 `SAGE-Modeler TSMC 0.18um`, typical `1.8 V / 25°C`를 명시한다. LEF는 `tsm3site`와 Metal1~Metal6, RC kit는 `t018s6mm.tch`와 `t018s6mlv.capTbl`이다. 따라서 **구두 안내의 180 nm 공정은 서버에 제공된 TSMC 0.18 µm digital standard-cell kit를 뜻한다고 보는 것이 가장 강한 현재 증거**다.

## 수행 범위

P2를 별도 디렉터리에서 다음 순서로 구현했다.

1. Genus에서 scan-cell 52종을 `avoid` 처리하고 physical용 netlist 재합성
2. slow/fast Liberty와 180 nm LEF/QRC를 사용하는 MMMC 구성
3. core floorplan과 양측 signal pin 배치
4. VDD/VSS core ring 및 standard-cell rail 연결
5. placement, pre-CTS optimization, CTS, post-CTS setup/hold optimization
6. Metal1~Metal6 signal routing
7. post-route coupled RC extraction
8. setup/hold timing, area, default-activity power, route DRC, connectivity 검사
9. DEF, SDF, SPEF, post-route Verilog와 RCDB 생성

## 결과

### Physical용 Genus netlist

| 항목 | 결과 |
|---|---:|
| scan cells | 0 |
| cells | 458 |
| area | 11,506.018 |
| worst data path | 3.324 ns |
| slack at 10 ns | +6.454 ns |

기존 P2 netlist는 일부 scan FF의 `SE/SI`를 논리 mux로 사용했기 때문에 Innovus가 불완전 scan chain으로 인식했다. physical용 netlist는 scan cell을 배제해 이 경고를 제거했다.

| SPEF nets | 504 |
| Innovus route DRC | 0 |

### Post-route timing

Clock period는 10 ns, setup/hold uncertainty는 각각 0.2 ns를 유지했다.

| 검사 | corner | slack |
|---|---|---:|
| setup | slow, 1.62 V, 125°C | +2.721 ns |
| hold | fast, 1.98 V, 0°C | +0.033 ns |

최초 run에서는 CDC 1단→2단 hold가 -34 ps였고, uncertainty를 낮추지 않고 post-CTS hold optimization으로 buffer를 추가해 +33 ps로 수정했다.

### Power

Innovus post-route power는 `1.15140032 mW`다. 이 값은 slow 1.62 V view와 기본 sequential/input activity 0.2를 사용하므로 기존 Genus typical vectorless 또는 VCD power와 직접 비교하지 않는다. CTS clock network는 약 0.1607 mW로 전체의 약 14%였다.

## 정확한 한계

이번 결과는 **180 nm digital core place-and-route**이며 다음은 아직 아니다.

- pad ring 또는 semiconductor package 설계
- foundry GDS stream-out
- foundry signoff DRC/LVS/antenna/metal-fill
- post-route gate simulation

현재 서버에서 standard-cell GDS/CDL, stream-out map, 공식 DRC/LVS rule deck과 matching Verilog cell model을 찾지 못했다. 따라서 Innovus 내부 route DRC 0을 foundry tapeout signoff로 표현하면 안 된다. 추가 PDK 자료가 제공되면 GDS/DRC/LVS와 post-layout simulation으로 확장할 수 있다.
