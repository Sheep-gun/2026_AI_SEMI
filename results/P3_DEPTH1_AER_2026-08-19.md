# P3 depth-1 AER 최적화 결과

## 변경 이유

P2 physical 비교에서 가장 큰 비용은 95개 clocked register였다. 그중 source별 depth-2 queue가 32 bits를 사용한다. 4-phase source는 acknowledge가 올 때까지 request를 유지하므로 queue가 가득 차면 event를 버리는 대신 source를 기다리게 할 수 있다.

P3는 다음을 유지한다.

- source별 2FF CDC
- 4×4 hierarchical round-robin
- registered elastic output
- held-request four-phase backpressure

변경점은 source별 2-bit count를 1-bit pending buffer로 줄인 것이다. 총 queued capacity는 32에서 16 events로 감소한다.

RTL: [`rtl/improved/aer_improved_depth1.sv`](../rtl/improved/aer_improved_depth1.sv)

## 기능 검증

| 환경 | main workload | CDC phase | 16-source order |
|---|---:|---:|---:|
| Vivado RTL | 139/139, error 0 | 192/192, error 0 | 16/16, error 0 |
| Vivado post-synthesis | 139/139, error 0 | 192/192, error 0 | 16/16, error 0 |
| Cadence Xcelium | 139/139, error 0 | 192/192, error 0 | 16/16, error 0 |

기존 burst, receiver stall, 16-source saturation과 source-0/source-15 hotspot을 모두 통과했다.

| metric | P2 | P3 |
|---|---:|---:|
| steady throughput | 1 event/cycle | 1 event/cycle |
| average latency | 18.438 cycles | 16.517 cycles |
| maximum latency | 44 cycles | 29 cycles |
| source-15 hotspot | 4 cycles | 4 cycles |

P3는 event를 내부 queue에 오래 보관하기보다 source backpressure를 먼저 적용해 측정 latency tail이 짧아졌다.

## B0 대비 남은 비용

P3도 B0보다 여전히 크다.

- area: B0의 약 5.71배
- default-activity power: B0의 약 11.16배
- 대신 throughput 4배, maximum latency 95% 이상 감소, round-robin fairness와 16-event buffering 제공

P3는 P2보다 효율적인 균형점이지만 수학적 최적해를 증명한 것은 아니다. queue를 완전히 제거한 구조는 더 작아질 수 있으나 receiver stall 흡수와 source decoupling을 잃기 때문에 별도 low-area variant로 다뤄야 한다.
